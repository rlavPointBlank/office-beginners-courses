Microsoft Office for Beginners

Microsoft Office (now usually sold as Microsoft 365) is a bundle of apps most workplaces, schools, and volunteer organizations run on day to day: Word for documents, Excel for spreadsheets and numbers, PowerPoint for presentations, Outlook for email and calendars, and OneNote for notes. This is a set of short, self-paced courses walking through each one from the ground up — no prior experience assumed.

Independent and unofficial. This isn't produced, reviewed, or endorsed by Microsoft — it's a personal project built to teach these tools to someone taking on a treasurer/volunteer-organizer role for the first time. "Microsoft," "Office," "Excel," "Outlook," "PowerPoint," and "OneNote" are trademarks of Microsoft Corporation, used here only to describe the software the course is about.

Every course below follows the same format: short lessons, a hands-on exercise, and a short quiz you need to pass to unlock the next chapter. Your progress in each is saved automatically in this browser. Pick any course to start, and jump between them freely — the sidebar in each has a link back here, and to the others.

Built with an Obsidian-vault, home-lab documentation habit rather than a classroom in mind — each course leans on a running example (a small volunteer organization's dues, donations, and board meetings) so the exercises feel like real work, not busywork.
